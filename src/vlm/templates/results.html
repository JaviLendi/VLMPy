Performance summary

infoPerformance Summary Info

  • CL / CD: Existing total lift and induced-drag coefficients. Their legacy reference area is the total area of all modeled panels.
  • CX, CY, CZ: Force coefficients in body axes: x forward, y right and z down.
  • Cl, Cm, Cn: Roll, pitch and yaw moment coefficients, using the right-hand rule. Lowercase Cl is roll; uppercase CL is lift.
  • New force and moment references: Main-wing planform area, span and mean aerodynamic chord. Moments use the area-weighted quarter-chord point, not the aircraft center of gravity.
  • Lift / Drag: Total lift and drag forces in newtons (N), from the flight condition used in the analysis.
  • Wing, horizontal and vertical stabilizer lift: Lift contribution of each surface, in newtons (N).

The solver is inviscid: it predicts induced drag, but not profile drag, separation or stall. The coefficient sets use different reference areas, so compare them with that distinction in mind.

Static aerodynamic derivatives

infoStatic Derivatives Info

  • Rows identify the coefficient; each value is its sensitivity to the variable named by the column, not the coefficient value shown in the summary.
  • Derivatives are estimated with central finite differences using a default perturbation of 0.1 degrees and are reported per radian.
  • Alpha / beta: Angle-of-attack and sideslip sensitivities.
  • Wing-section columns: Sensitivity to the configured flap or aileron deflection for that wing section.
  • The calculation restores the original flight condition and geometry. These are static derivatives; rates, dynamic stability and viscous effects are not modeled.

infoLoads and Coefficients Info

  • CL / CD: Spanwise strip coefficients; CD is induced drag in this inviscid solver.

Field data

Surface diagnostics

infoSurface Diagnostics Info

  • Induced velocities: Velocity induced on the surface panels by the vortex system.
  • Gammas: Circulation strength of the vortex on each panel.
  • Wing curvature: Curvature (camber) of the lifting surface.
  • 3D / 2D: The same fields shown as a 3D view or as a flat 2D map of the surface.

Save and load

infoSave and Load Info

  • Save results: Stores the configuration, flight condition, circulation solution, existing CL/CD and the six integrated force and moment coefficients.
  • Static derivatives: Included when they have been calculated and are available in the current solution state.
  • Load results: Restores saved arrays and reconstructs the integrated coefficients for older result manifests.
  • Legacy PKL state: Loads a state from an older .pkl file.

Angles of attack

infoAngles of Attack Info

  • Range: Generate an ascending or descending sequence in degrees from the start, end and positive step. The end is included when it falls on a step.
  • Angles of attack: Edit the generated list or enter a custom comma-separated list in degrees.
  • Calculate: Runs the analysis for each angle. The API response contains CL, CD and the six integrated force and moment coefficient series.
  • Available plots: Plot CL, CD, CX, CY, CZ, Cl, Cm or Cn against alpha. Each button replaces the current Plotly chart. Calculate a sweep first.
  • CD is induced drag only. The VLM does not model profile drag, separation or stall.
